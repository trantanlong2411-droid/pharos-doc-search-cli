Docs Search CLI

A real, dependency-free Node.js command-line utility built on Pharos Developer Docs MCP. Ask a natural-language question; get a concise excerpt and only source URLs returned by the MCP server. Missing or uncited answers are refused.

What it does

  1. Takes a question from the terminal, not a hardcoded prompt.
  2. Connects to https://docs.pharos.xyz/~gitbook/mcp and lists actual tools.
  3. Calls askQuestion or searchDocumentation using their discovered input schema.
  4. Prints a short answer excerpt and URLs that really came from the MCP tool.
  5. If a question has no reliable documented result, prints No good answer found.

Run on Windows PowerShell

Clone the source folder (or download the project ZIP), open PowerShell inside the doc-search-cli directory and run:

node -v
node .\bin\pharos-docs.mjs --tools
node .\bin\pharos-docs.mjs "How do I deploy a contract on Pharos?"
node .\bin\pharos-docs.mjs "What is Pharos Atlantic Testnet?"
node .\bin\pharos-docs.mjs "Where is the guide for Quantum Banana X999?"
npm.cmd test

Node.js 20 or newer is needed; no installation or secret key is required.

[Real documentation excerpt returned by the live MCP server]
